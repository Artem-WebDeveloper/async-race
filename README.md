# Async Race

## Deploy - https://artem-webdeveloper.github.io/async-race/

### Setup Dev

Проект требует локальный сервер, PORT: `3000`.

Для запуска нужно:

1. Клонировать [сервер]() и запустить его
2. Создать `.env` файл в корне проекта:

```bash
VITE_API_URL=http://127.0.0.1:3000
```

3. Установить зависимости и запустить проект:

```bash
npm install
npm run dev
```
